# Stage automatic deletion in Jet Trash

The Utility model may compile a natural-language Autodelete prompt once into a bounded structured rule, but that draft cannot execute until the GUI shows its interpretation and matches and the user approves it. Scheduled cleanup evaluates only the stored deterministic rule; editing its source or structure returns it to draft, and model output has no authority to issue deletion Commands. Approved rules may select only Conversations protected by none of: active Run, pending turn, enabled schedule, shared or private pin, dirty Workspace, unpushed work, or unresolved Effect; matches first move into recoverable Jet Trash with a recorded reason. They use a configurable grace period defaulting to 30 days and request Harness-native deletion after that period only when explicitly authorized to delete everywhere. Unavailable, invalid, or ambiguous Utility-model output fails closed.

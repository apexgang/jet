# Use framed JSON control and raw binary data

The v1 Jet protocol uses a small length-prefixed envelope over both Unix sockets and SSH standard I/O. Commands, Queries, Events, acknowledgements, errors, handshakes, and Presentation metadata use strict JSON control frames capped at 1 MiB; terminal bytes and Artifact content use raw binary data frames in chunks capped at 256 KiB. Parsers enforce a nesting depth of 64 and explicit collection and allocation bounds, reject oversized declarations before allocation, and apply no compression in v1. Wire values use UUID strings, signed Unix milliseconds, decimal strings for sequences and revisions, integer milliseconds for durations, and explicit IANA schedule zones. Rust wire DTOs generate JSON Schema plus Swift and TypeScript models and contract tests. The handshake names `json-v1` as the only v1 codec while reserving codec negotiation for a benchmark-justified binary encoding. Jet does not adopt JSON-RPC or gRPC in v1.

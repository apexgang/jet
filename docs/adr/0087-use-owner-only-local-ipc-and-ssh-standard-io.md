# Use owner-only local IPC and SSH standard I/O

Jet exposes no TCP listener in v1. Local clients use an owner-only Unix socket with peer-identity validation. Core-initiated remote connections spawn `jetd connect --stdio` through the system SSH client using an argument array, honor the user's SSH configuration, agent, and `known_hosts`, and never disable host-key checking or accept a changed key automatically. An unknown host requires a separate explicit host-key confirmation before Jet Pairing, so SSH authenticates the Plane endpoint and Pairing authorizes Jet control as distinct checks; Tailscale SSH follows the same Jet authorization layer. Remote clients must satisfy both SSH authentication and Jet's paired-client signature before leaving a deliberately restricted initial handshake. This defense-in-depth path applies ASVS 1.2.5, 6.3.4, 8.3.1, 8.3.3, 13.2.2, and 13.2.6.

# Treat third-party Crafts as trusted code in v1

A third-party Jet Craft is arbitrary executable code installed only after explicit confirmation of its repository, publisher claims, pinned commit, artifact hash, declared permissions, and same-user trust implications. Jet launches it with a sanitized environment and isolated state directory, injects no credentials, and brokers Jet-owned operations according to declared permissions, but v1 does not claim those controls contain malicious code already executing as the user. Available native sandboxing is defense in depth; portable mandatory containment is deferred because dynamically installed macOS and heterogeneous Linux executables do not share one dependable enforcement mechanism. Bundled Crafts remain signed, reviewed parts of the Jet release.

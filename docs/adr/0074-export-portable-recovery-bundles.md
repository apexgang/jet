# Export portable Recovery bundles

The core can export and validate a Recovery bundle containing a consistent SQLite snapshot, referenced Artifacts, installed Craft metadata, and non-secret configuration. Provider credentials, native authentication state, Plane and Client identities, Pairings, service ownership, original Project repositories, and Workspace directories are excluded by default; users may explicitly include selected Workspace patches or snapshots. Encrypted bundles use the binary [`age` v1 format](https://age-encryption.org/v1) without ASCII armor, supporting only X25519 recipients or scrypt passphrases in v1; SSH recipients, plugins, and experimental algorithms are excluded. Jet pins a minimal Rust implementation behind an internal Interface and enforces its incremental binary-size budget. An explicit warned unencrypted export is allowed only after showing the included data, and losing the passphrase or recipient private key is unrecoverable. Import authenticates the stream, manifest, and payloads and verifies schema or protocol compatibility before staging. Every portable import creates Recovered copies with new Conversation identities and disabled schedules; only two-phase Plane transfer may preserve authority, while a local Recovery-snapshot restore may preserve identities only after validating Deletion-ledger and Authority-fence state. This protection is independent from v1's unencrypted live SQLite store and applies ASVS 11.1.1 through 11.1.4, 11.2.1 through 11.2.5, 11.5.1, and 14.2.4.

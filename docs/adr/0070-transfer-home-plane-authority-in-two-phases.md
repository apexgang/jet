# Transfer Home Plane authority in two phases

A Plane transfer requires no active Run and temporarily pauses the Conversation's schedules. The source prepares Conversation state, queued turns, schedules, Artifacts, provenance, and an optional Workspace snapshot; the controlling GUI streams them between its authenticated Plane connections. The target validates protocol and schema compatibility plus Project mapping and imports transactionally as a Prepared transfer that cannot run or fire schedules. The source then durably commits both a thirty-day Transfer tombstone for content recovery and a permanent, content-free Authority fence outside rollback-capable state, bound to the retired authority epoch, transfer identity, and target Plane; only after observing that commit may the client activate the prepared target. Before source commit only the source is authoritative, and afterward the fence prevents it or any restored local snapshot from continuing the original authority. Every step is retryable by the same identity and bundle hash. Credentials and native Harness session files are never copied; the target follows the existing native-resume or context-package rules. The fence and recovery boundary apply ASVS 2.3.1, 2.3.2, 14.2.4, and 14.2.7.

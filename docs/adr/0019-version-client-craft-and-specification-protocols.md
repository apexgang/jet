# Version client, Craft, and specification protocols

Client, Craft, and fuel-helper protocols negotiate major and minor schema versions and capabilities independently, with additive minor evolution. Within a negotiated compatible minor, readers ignore unknown optional object fields but reject unknown message kinds, Commands, and security-sensitive variants; opaque Presentation blocks remain preservable for generic rendering. GUI clients and `jetd` support the current and previous applicable protocol majors, incompatible peers remain non-mutating or disabled with diagnostics, and every Craft specification explicitly declares both its own schema version and its supported Craft-protocol range. An active execution retains compatibility with its negotiated protocol major for its entire lifetime: a new major may download and stage, but activation waits while an active helper or Craft requires an unsupported major. The GUI offers wait, finish, or explicit stop; only a Craft digest revoked by signed Jet release metadata may be force-disabled automatically.

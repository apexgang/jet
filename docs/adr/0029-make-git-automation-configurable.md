# Make Git automation configurable

Jet exposes independent Git automation settings for lazy branch creation, successful-turn commits, pushes, and GitHub draft pull requests, with Project defaults and per-Conversation overrides. All settings default off, all operations remain manually available, and Jet never automatically commits a failed turn, force-pushes, merges, or deletes a branch. The branch naming prefix or template is editable in GUI settings and the proposed branch name remains editable before creation. Commit messages and pull-request titles and bodies are generated by the Utility model using the actual Change checkpoints plus optional Plane-wide Git message instructions entered in the GUI; Project-specific and one-operation message instructions are deferred beyond v1. Deterministic fallback text is used when model generation is unavailable.

# Link one pinned SQLite build into jetd

Only `jetd` links a pinned SQLite build with the required WAL and FTS5 capabilities. Authoritative state uses WAL with `synchronous=FULL`, so an acknowledged commit is synchronized against operating-system crash or power loss; Jet improves throughput through bounded transactions and batching rather than weakening durability. Temporary and rebuildable indexes may use explicitly weaker settings only in separate stores whose loss cannot roll back authoritative state. This modest size cost produces identical migration, search, transaction, and corruption behavior on supported Planes and avoids runtime dependence on distribution-specific SQLite features. `jetfueld`, Jet Crafts, and client libraries do not link SQLite. The documented integrity and retention boundary applies ASVS 14.2.4.

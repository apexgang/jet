# Standardize account Usage records

Every Jet Craft exposes Provider-reported quota windows and Jet-observed consumption as Usage records with source, scope, estimation, finality, Account binding, Model, Conversation, Run, Plane, and time metadata. A GUI groups records from connected bindings into their federated Provider account, uses the freshest Provider response without summing duplicate quota windows, and clearly distinguishes unreachable, stale, and estimated data. Jet-observed consumption may be summed only after deduplication by Run and native usage identity, and the GUI never claims an account-wide total when contributing Planes are unknown. History covers only Jet-observed activity, and the core supplies time-series and aggregation data for GUI quota diagrams and usage plots while retaining raw Harness detail.

# Version bundled products together and protocols separately

The GUIs, `jetd`, `jetfueld`, and bundled Codex and Claude Code Crafts ship under one Jet release version. Client protocol, Craft protocol, and Craft-spec schema versions evolve independently according to their compatibility rules. Third-party Crafts retain their own semantic versions and declare supported protocol ranges, allowing product releases without pretending every external Adapter shares Jet's lifecycle.
